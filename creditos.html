Português

1. Desenvolvimento e Conceção

Este website foi concebido, projetado e desenvolvido por João P.

2. Assistência de Inteligência Artificial

Foi utilizada a ferramenta de IA Gemini (Google) como assistente técnico no desenvolvimento do projeto, prestando apoio no depuramento (debugging) de código Three.js e JavaScript, na otimização de desempenho, na criação e estruturação de páginas HTML/CSS e na geração de elementos gráficos secundários e assets visuais.

3. Recursos e Bibliotecas de Terceiros

Este projeto faz uso de bibliotecas de código open-source, bem como de texturas, mapas HDRI e outros elementos gráficos disponibilizados publicamente pelos sites ambientecg.com, polyhaven.com e opengameart.org, aos quais se agradece e reconhece o respetivo trabalho.

English

1. Development and Design

This website was conceived, designed, and developed by João P.

2. Artificial Intelligence Assistance

The AI tool Gemini (Google) was used as a technical assistant during the development of this project, providing support in code debugging (Three.js and JavaScript), performance optimization, HTML/CSS page layout and structuring, as well as the generation of secondary graphic elements and visual assets.

3. Third-Party Resources and Libraries

This project utilizes open-source code libraries, as well as textures, HDRI maps, and other graphic assets publicly provided by ambientecg.com, polyhaven.com, and opengameart.org, whose contributions are hereby gratefully acknowledged.
